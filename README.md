# Marvin Seyfarth — Research Website

Public Quarto website published at <https://marseyf.github.io>.

## Privacy boundary

This repository contains only approved public material. It has no credentials for, automated access to, or direct synchronization with the private PhD Wiki. Articles are newly written syntheses and use public citations.

Private evidence notes and pre-publication drafts live in a separate, non-public workbench that is not connected to this repository.

## Local preview

```bash
quarto preview
```

## Publication

A push to `main` runs `.github/workflows/publish.yml` and deploys `_site` through GitHub Pages. Publishing remains approval-gated: drafts are prepared privately and moved into `posts/<slug>/index.qmd` only after review.

## Cost

Quarto is open source. GitHub Pages and standard GitHub Actions are free for this public repository. A custom domain or optional third-party services would be separate costs and are not configured.
